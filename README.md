# پنل مدیریت NOVA

پنل مدیریت فروشگاه NOVA برای مشاهده و مدیریت کاربران و محصولات. این پروژه با React، Vite و TypeScript ساخته شده و رابط فارسی RTL و انگلیسی LTR، تم روشن و تاریک و چیدمان دسکتاپ دارد.

## وضعیت و محدوده

این پیاده‌سازی بر اساس شرح چالش توسعه یافته و امکاناتی فراتر از حداقل خواسته‌شده، مانند داشبورد، جزئیات رکورد، ویرایش و حذف و Drawer موبایل، نیز دارد. رابط کاربری به FakeStoreAPI متصل است؛ این سرویس آزمایشی است و تغییرات نوشتنی آن تضمین نمی‌شود که روی سرور باقی بمانند.

> **توضیح ارزیابی:** طبق کارنامه، استفاده از TanStack Query در کنار Redux Toolkit نیازمند توضیح معماری است. در این پروژه Redux برای وضعیت سراسری رابط و نشست (زبان، تم، احراز هویت و تغییرات موقت رکوردها) استفاده می‌شود؛ TanStack Query مسئول داده‌های سروری، چرخه درخواست، cache و وضعیت‌های loading/error است. این انتخاب عمداً تفکیک «وضعیت رابط» از «داده API» را فراهم می‌کند، اما با الزام صریح سند برای استفاده از Redux Toolkit در state عمومی تفاوت دارد و یک trade-off محسوب می‌شود.

## پیش‌نیازها

- Node.js نسخه 24
- pnpm نسخه 10.14.0

نسخه Node در `.node-version` و نسخه package manager در `package.json` ثبت شده است.

## راه‌اندازی

```bash
pnpm install
Copy-Item .env.example .env.local
pnpm dev
```

برنامه در [http://127.0.0.1:5173](http://127.0.0.1:5173) اجرا می‌شود. مقدار `VITE_FAKE_STORE_API_URL` در `.env.local` آدرس پایه FakeStoreAPI یا یک سرویس سازگار با آن است. مقدار پیش‌فرض `https://fakestoreapi.com` است.

## فرمان‌ها

```bash
pnpm dev           # اجرای محیط توسعه
pnpm build         # بررسی TypeScript و ساخت نسخه انتشار
pnpm lint          # اجرای ESLint
pnpm test          # اجرای تست‌های Playwright
```
## ساختار پروژه

```text
src/
├── assets/          # فونت‌ها و آیکون‌ها
├── Components/      # اجزای ویژه صفحات و Layout
├── Dictionary/      # متن‌های فارسی و انگلیسی
├── Modals/          # دیالوگ‌ها و فرم‌های modal
├── Pages/           # صفحات و نقاط ورود مسیرها
├── Redux/           # Store و Sliceهای وضعیت سراسری
├── Routes/          # مسیرها و محافظت مسیرها
├── Shared/          # کنترل‌ها و اجزای قابل استفاده مجدد
├── Storage/         # ذخیره‌سازی نشست، ترجیحات و تغییرات موقت
├── types/Enums/     # نوع‌ها و شناسه‌های منابع
├── Utils/
│   ├── api/         # Axios، Query و پردازش پاسخ
│   └── services/    # سرویس‌های احراز هویت و منابع
└── Validations/     # Schemaهای اعتبارسنجی فرم
```

## داده، state و API

تمام درخواست‌ها از Axios instance مستقل عبور می‌کنند و آدرس پایه از `VITE_FAKE_STORE_API_URL` خوانده می‌شود. timeout ده ثانیه است و پاسخ‌های API به شکل type-safe بررسی می‌شوند. TanStack Query داده‌های محصولات، کاربران، دسته‌بندی‌ها و جزئیات را مدیریت می‌کند؛ cache داده‌های فهرست ۶۰ ثانیه stale و تا ۵ دقیقه نگهداری می‌شود. تلاش مجدد خودکار و refetch هنگام focus یا reconnect غیرفعال است.
